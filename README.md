# App Privacy Center

Public privacy, terms, and support pages for apps published by **gzx**.

Live site: <https://gzx543097079.github.io/App-Privacy-Center/>

## Structure

Each app has an isolated directory under `apps/`:

```text
apps/
  nimblefive/
    index.html
    privacy/index.html
    terms/index.html
    support/index.html
```

To add an app, create `apps/<app-slug>/`, add its legal and support pages, add a card to the root `index.html`, and add the public URLs to `sitemap.xml`.
